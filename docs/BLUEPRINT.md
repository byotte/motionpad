# MotionPad 청사진
각 항목 앞에 [필수] [희망] [금지] [미정] 중 하나를 붙인다.


## 1. 궁극 목표 (한두 문단)
- 1. 단일 이미지 한 장만으로 라이브투디 효과를 만들기 (추후 폰 움직이는 배경화면 등에 활용), 2. 이미지를 볼을 잡아당기거나 머리를 쓰다듬는 등 상호작용하며 놀기. 둘은 우선순위 없이 둘 다 반드시 가능해야 한다.
- 좋아하는 이미지 한 장을 갖고 있는 사람이라면 누구든 쉽게 열어서, 별도의 프로그램 공부 없이, 5분 안에 만족스런 결과물을 얻어야 한다.
- 포토샵이나 클립스튜디오처럼, Ai 특유의 UI보다는 익숙한 기성 프로그램만큼 완성도 있는 디자인.
- 핸드폰과 PC 양쪽 모두 최적화.

## 2. 우선순위 (위가 이긴다. 충돌하면 이 순서로 판단)
1. 조작 난이도
2. 결과물 완성도 (유저가 재미있게 만지고 놀 수 있어야 함)
3. 프로그램 경량화 (웹 연결 혹은 html파일 하나면 누구든 열수 있을 것)

## 3. 절대 원칙
[필수] 반드시 지켜야 할 것: 단일 HTML로 실행, 서버 전송 금지, 한눈에 파악되는 UI, 디자인 통일성
[금지] 절대 하면 안 되는 것: 반복되는 버그, 개발 과정의 토큰 낭비
[미정] 아직 결정하지 못한 원칙: 나는 갤럭시 폴드8 유저라 보편적 스마트폰과 화면비가 다르다. 반응형UI를 만들 때 이로인해 선택해야할 상황에 놓일 수 있다.

## 4. 레이아웃 지향점
- 화면 구조 원칙: 모바일을 고려하여 조작화면 최대한 크게, 파일 관련 프로젝트 메뉴들은 최상단에, 옵션 조정 항목은 PC기준 오른쪽에. (모바일은 별도)
- PC 화면에서의 배치: 상위 메뉴들(파일 관련, 설정, 플레이모드 진입 등)은 화면 최상단, 좌측 크게 편집화면, 우측 옵션조정란
- 모바일 세로 화면에서의 배치: 편집화면 최대한 크게, 옵션 조정 하단에. 단 변화를 눈으로 보면서 조정해야 하므로 스크롤을 내려도 위에 캔버스를 볼 수 있어야 함.
- 모바일 가로·폴더블에서의 배치: 가로폭이 더 길 때는 PC구조, 세로 폭이 더 길 때는 모바일 구조 적용
- 크기가 변하면 안 되는 요소: 현재 없음
- 디자인 톤: 3가지 버전 중에 유저가 고를 수 있게 하라. 컨셉은 현재 다크모드/모노모드/따뜻한 톤으로 나뉘어있으나 추후 변경 가능
- 도움말 방식: 초보자 친화적을 지향하므로, 메뉴마다 고정된 영역에서 안내문구가 나오길 희망한다. 예를 들어 지우개 툴을 누르면 '지우개가 선택되었습니다. 선택영역을 지워보세요' 같은.

============= 선택영역 설정 옵션

### [마술봉]
- 목적: 캔버스 특정 부위를 클릭하여 유사한 값을 한번에 선택영역 지정한다
- 위치: 캔버스 상단 툴박스
- 포함 기능:
  [필수] 선택영역에 추가 혹은 제외 옵션 — 해제 상태에서 클릭하면 이전 영역은 리셋되고 새로운 영역이 지정되고, 추가 상태에서 클릭하면 이전 영역에 더해짐. 제외 상태에서는 교집합 영역을 제외함.
  [필수] 범위 지정 — 선택된 영역범위 주변 포함정도 선택. 줄일 수록 좁아지고 올릴 수록 넓어짐. 한번에 완벽한 영역을 선택하지 못 할 시 실제 범위를 눈으로 보며 조절 가능.
  [필수] 더할 영역 뺄 영역 지정 옵션 — 옵션 선택 후 마술봉 클릭하면 해당 영역 포함하거나 제외함
- PC와 모바일의 차이: 없음
- 초보가 처음 봤을 때 알아야 할 것: 일단 클릭한 다음 범위를 지정할 수 있음.
- 완료 판정: 최대한 원클릭으로 만족스러운 결과물을 위해 노력하고, 범위 지정으로 미흡한 부분을 보완함. 정확도 개선은 끝이 없기 때문에 어느 정도 실용성 검증되면 검토 후 결정.

### [올가미]
- 목적: 캔버스 원하는 부위를 덧그려 그 안의 외형을 자동 선택한다
- 위치: 캔버스 상단 툴박스
- 포함 기능:
  [필수] 선택영역에 추가 혹은 제외 옵션 — 해제 상태에서 새로 그리면 이전 영역은 리셋되고 새로운 영역이 지정되고, 추가 상태에서 그리면 이전 영역에 더해짐. 제외 상태에서는 교집합 영역을 제외함.
  [필수] 이어 그리기 옵션 — 모바일 환경에서 한번에 덧그리기 어려울 수 있으므로, 끊어서 긋더라도 전체 선으로 인식. 단, 마지막 점이 출발점 근처에 닿으면 자동 완료로 판정.
  [필수] 자석 올가미 — 대충 외곽을 따라 덧그려도 외곽선에 가서 자동으로 붙음
  [필수] 간략 범위지정 — 대충 주변을 둘러싸서 올가미로 선택하면, 자동으로 그 안의 외곽선을 따라 영역선택 됨.
  [희망] 영역범위 지정 — 선택된 영역범위 주변 포함정도 선택. 줄일 수록 좁아지고 올릴 수록 넓어짐. 한번에 완벽한 영역을 선택하지 못 할 시 실제 범위를 눈으로 보며 조절 가능. (마술봉에서는 필수지만 올가미는 최대한 툴 자체만으로 해내도록 함)
- PC와 모바일의 차이: 없음
- 초보가 처음 봤을 때 알아야 할 것: 자석/간략 범위지정 툴의 종류와 차이점 직관적 인식
- 완료 판정: 최대한 원클릭으로 만족스러운 결과물을 위해 노력하고, 범위 지정으로 미흡한 부분을 보완함. 정확도 개선은 끝이 없기 때문에 어느 정도 실용성 검증되면 검토 후 결정.

### [도형]
- 목적: 캔버스에 사각형/원(타원 포함) 모양 선택영역 지정
- 위치: 캔버스 상단 툴박스
- 포함 기능:
  [필수] 사각형/원 선택 — 목적에 맞는 모양 선택
  [필수] 선택 후 모양 커스텀 — 모바일 환경에서 원모양 선택 후 두 손가락으로 터치하여 크기/비율/기울기 조절 가능.
  [필수] 선택영역에 추가 혹은 제외 옵션 — 해제 상태에서 새로 그리면 이전 영역은 리셋되고 새로운 영역이 지정되고, 추가 상태에서 그리면 이전 영역에 더해짐. 제외 상태에서는 교집합 영역을 제외함.
- PC와 모바일의 차이: 모바일에서는 두 손가락 터치로 커스텀 가능/PC에서는 대체할 방법 모색해야 함.
- 초보가 처음 봤을 때 알아야 할 것: 모바일 시 도형 그린 후 커스텀 가능
- 완료 판정: 기능 수행

- 목적: 선택영역을 변형시키지 않고 위치만 이동

- 포함 기능:
  [필수] 이동 기능
- PC와 모바일의 차이: 없음

- 완료 판정: 기능 수행

### [뒤로가기(<-)/다시 실행(->)]
- 목적: 프로그램 내 모든 실행에 대해 취소 혹은 다시 실행
- 위치: 캔버스 상단이나 하단 잘 보이는 위치
- 포함 기능:
  [필수] 뒤로가기 혹은 다시 실행
  [희망] 프로그램 내 모든 실행에 대해 적용. 불가능할 경우 캔버스 내 툴에 대해 적용. 
- PC와 모바일의 차이: 없음
- 초보가 처음 봤을 때 알아야 할 것: 존재 인식
- 완료 판정: 기능 수행

### [캔버스 확대/축소/캔버스 이동/터치 보정]
- 목적: 캔버스 제어 기능 툴
- 위치: 캔버스 하단
- 포함 기능:
  [필수] 캔버스 확대(+), 축소(-), 100%(원래 크기. 확대 혹은 축소됐을 경우 해당 % 표시기능 겸용) 제어/ 이미지 전체를 이동시키는 키/ 터치 시 손가락에 의해 가려지는 영역을 고려해서 영점을 좀 더 위로 잡게 하는 옵션 각각 반영 
- PC와 모바일의 차이: PC환경에서는 스페이스 바 누른채 캔버스 누르면 캔버스 이동 기능 적용
- 초보가 처음 봤을 때 알아야 할 것: 없음
- 완료 판정: 기능 수행


============= 선택영역 제어 옵션

- 포함 기능:

### [외곽까지 흔들기]

- 위치: 아직 미정. 고민 필요.
- 포함 기능:
  [필수] 적용 시 해당 선택영역을 이미지 위로 올리고 움직이고난 후의 빈자리를 주변 배경에서 얻은 정보로 자동 채움. 
  [희망] 다중 적용 — 현재 한 부위만 적용가능하게 코딩되어 있음. 다중적용안 모색필요.
- PC와 모바일의 차이: 없음
- 초보가 처음 봤을 때 알아야 할 것: 초보가 이해하기 매우 어려운 기능. 접근성을 높일 수 있도록 친절하고 직관적인 설계 필요.
- 완료 판정: 여러 이미지에서 안정적인 퀄리티의 결과물 확보. 그리고 [희망] 기능 검토 후 반영/미반영 결정하여 완료 판정.

### [선택영역 옵션 설정]

- 위치: 미정. 프로그램 설정 메뉴에 넣을지 선택영역 제어 옵션에 끼워넣을지 미정.

- 완료 판정: 기능 수행

- 포함 기능:
  [필수] 축 지정 — 선택된 부분은 고정. 멀 수록 움직임 큼

- 초보가 처음 봤을 때 알아야 할 것: 세부 옵션이므로 처음엔 접힘 메뉴로. 친절한 도움말 필요.
- 완료 판정: 기능 수행

### [전체 움직임]
- 목적: 한번의 터치만으로 전체 그림이 살아있다는 느낌을 주기
- 위치: 가장 큰 변화이므로 이미지 열자마자 한눈에 보이는 위치.

  [필수] 호흡 — 이것만 해도 정지된 느낌에서 탈피. 강조 조절 필수.
  [희망] 그 외 전체 적용할만한 옵션 — 제시 필요.

- 초보가 처음 봤을 때 알아야 할 것: 직관적인 변화와, 기능 On/Off 방법.

### [부분 움직임(자동)]

- 위치: 옵션창

  [필수] 움직임 방향 선택 — 상하/좌우/대각선 2종/확대 및 축소

  [희망] 움직임 프리셋 — 자주 쓰는 자동 움직임은 프리셋으로 만들어 여러 설정을 미리 적용해 놓는다. (ex. 머리카락, 옷자락, 꼬리 등)
- PC와 모바일의 차이: 없음
- 초보가 처음 봤을 때 알아야 할 것: 터치 시 움직임과의 구분

### [부분 움직임(터치)]

## 6. 이전 작업에서 생긴 문제 (반면교사)
- 아스트라가 반복한 실수와, 그때 원했던 결과: 1. 레이아웃을 시안에서 결정한 뒤, 본 프로그램에서 이식 과정에서 누락 다수 발생. 여러차례 지적에도 고쳐지지 않음. 2. 마법봉과 자석 올가미 기능의 부진한 성능. 여러차례 개선에도 나아지지 않음. 3. 상위모델 (아스트라 하이)에서 정확히 분석하고, 하위 모델(6.1Sol 라이트)은 이행해내지 못 함.
- 다시는 보고 싶지 않은 상황: 비효율적인 토큰 소모. 문제가 발생하고, 그거 분석시키고, 다시 수정하다가 토큰이 다 소모되어 5시간동안 아무 것도 못 하는 상황.
