# 얼굴 표정 · 맞은 자리 반응 설계 (확정안, 미구현)

2026-11-16 사용자와 논의해 확정한 내용. **아직 구현하지 않았다.** 구현 세션은 이 문서부터 읽는다.
대원칙: **그림 한 장으로 다 한다.** 반응 그림을 따로 그려 넣는 방식, AI 생성, 서버 전송은 쓰지 않는다.

## 1. 버린 것
- 반응 그림 바꿔 끼우기(그림 추가 필요) · AI 표정 생성(원칙 위반)
- **입 벌리기**: 그림에 없는 입 안을 만들어야 해 어색함. 다문 입 모양 바꾸기만 한다.
- **깨짐**: 갈라짐의 다음 단계라 뺌.
- 활짝 감은 웃는 눈: 눈웃음까지만.
- 가변 섹션 번호(체크하면 아래 번호가 밀리는 방식): 같은 섹션을 같은 번호로 부르지 못하게 되어 뺌.

## 2. 패널 구조 (번호 고정)

```
1. 영역
┌───────────────────────────────────────┐
│ 2. 얼굴 · 눈 깜빡임   [선택]   ☐ 적용      │  ← 다른 섹션과 구분되는 테두리 상자
└───────────────────────────────────────┘
3. 몸체 움직이기        (처음 시작할 때 이것만 열림 — 지금처럼)
4. 부분 움직이기
   4-1 연속 움직임
   4-2 터치 움직임
```
- 지금의 '4. 눈 깜빡임'이 2번 자리로 올라가 얼굴을 품는다. 섹션 수는 지금과 같은 4개.
- **'적용' 꺼짐**: 상자 안 한 줄만, 흐린 색. **켜는 순간** 1·3·4번처럼 섹션 첫 줄이 강조색이 되고 펼쳐지며 '얼굴 1'이 생기고 눈 찍기 안내가 시작된다.
- 얼굴이 하나도 없으면 3·4번의 표정 칸은 **아예 보이지 않는다**(초보자 화면은 지금과 같다).
- 정의(2번) → 사용(3·4번) 순서라 위에서 아래로 내려오면 완성되는 흐름이 유지된다.
- 실제 화면이 복잡해 보이면 다시 고민한다(사용자 조건).

## 3. 2번 '얼굴 · 눈 깜빡임' 내용

```
얼굴 목록: [얼굴 1] [얼굴 2] [+ 얼굴 추가]     (최대 3)
 ├ 부위 입력
 │   눈: 눈꼬리 두 점 + 윗꺼풀 가운데 + 아랫꺼풀 가운데 (눈 깜빡임 입력과 겹치는 건 다시 묻지 않음)
 │   입: 다문 입(벌린 그림이면 그 상태)의 입꼬리 양쪽 + 가운데, 점 3개
 │   눈썹: 따라 그리는 선 (모양·위치 좌표만, 굵기는 모름) — 눈썹을 쓰는 표정에서만 요구
 │   귀: 따라 그리는 선 — 홍조 세부 옵션의 '귀도 붉게'를 켤 때만 요구
 ├ 눈 깜빡임 (지금 4번 내용)
 └ 표정: [웃음] [부끄러움] [울먹임] [화남] [놀람]   → [표정 상세 세팅] (따로 뜨는 창)
```
- 얼굴마다 부위와 표정 다섯 개를 따로 가진다. 눈 깜빡임이 눈 6개까지라 얼굴 최대 3.
- 부위 입력은 선택 도구의 확대경(루페)을 재사용한다(폰).
- 뺨은 입력받지 않는다(§7 추정).

## 4. 표정 = 사용자가 만드는 것, 프리셋은 출발점
- 다섯 표정(웃음 · 부끄러움 · 울먹임 · 화남 · 놀람)은 **프리셋 값으로 시작하는 사용자 표정**이다. 고친 값은 프로젝트에 저장되고, 표정마다 따로 저장된다(웃음을 고쳐도 화남은 그대로). '프리셋으로 되돌리기' 버튼.
- 영역들은 이 표정을 **이름으로 가져다 쓴다**(§6).

### 표정 상세 세팅 창 (RPG 얼굴 설정식, 고르면 바로 반영 · 얼굴 확대 미리보기)
```
[○○ 프리셋에서 시작]  [프리셋으로 되돌리기]
눈썹        앞머리 ━●━   가운데 ━●━   꼬리 ━●━
윗눈꺼풀    앞 ━●━       가운데 ━●━   뒤 ━●━
아랫눈꺼풀  앞 ━●━       가운데 ━●━   뒤 ━●━
입          꼬리 높이 ━●━  꼬리 좁히기 ━●━  가운데 ━●━  떨림 ━●━
☐ 좌우 따로 조정        (기본은 좌우 같이. 켜면 비대칭 표정 가능)
▸ 홍조 · 귀 · 땀방울 · 눈물 · 만화 기호 · 진할 때(연타) 추가 효과
```
- 4-1·4-2의 [다듬기] 버튼에서도 이 창이 바로 열린다(섹션을 오갈 필요 없음).

### 프리셋 출발값 (방향만, 수치는 구현 때 눈으로 맞춘다)
| 표정 | 눈썹 | 눈 | 입 | 홍조·기호 |
|---|---|---|---|---|
| 웃음 | 살짝 올림 | 눈웃음: 눈꼬리 살짝 내리고 아랫꺼풀+애교살을 함께 올림 | 꼬리 올림 | 볼 살짝, 반짝이 |
| 부끄러움 | 머리 살짝 올림 | 약한 눈웃음 | 꼬리 작게 올림, 조금 좁힘 | 홍조 진하게, 땀 2~3 |
| 울먹임 | 머리 올리고 꼬리 내림(슬픔형) | 윗꺼풀 살짝 덮음, 눈물 맺힘 | 꼬리 내림, 가운데 살짝 올림, **입술 떨림** | — |
| 화남 | 머리 내리고 꼬리 올림, 눈두덩까지 함께 내림(앞쪽 더) | 찡그림 | 꼬리 내림, 앙 다묾 | 얼굴 붉게, 💢 |
| 놀람 | 가운데 올림(앞머리도 올릴지 세부 옵션) | 윗꺼풀 가운데 올림 · 아랫꺼풀 가운데 내림(눈동자 늘어남 최소, 이동 상한) | **'흡'**: 앙 다묾 + 꼬리 좁혀 오므림 | 땀 1 |

## 5. 그리는 방식 (전부 원본을 휘거나 위에 그린다 — 새 그림 생성 없음)

### 픽셀 유동화식 변형
- 기준점(눈썹 3 · 윗꺼풀 3 · 아랫꺼풀 3 · 입 3, 좌우)을 정한 만큼 밀고 둘레가 부드럽게 따라오게 한다.
- **눈썹**: 휘는 범위를 위로는 이마까지 넓게, 아래로는 눈두덩까지 부드럽게 줄인다 → 앞머리가 갑자기 꺾이지 않는다. 눈 자체는 움직이지 않게 아래 경계만 조심.
- **눈**: 눈 깜빡임의 눈꺼풀 처리를 응용. 웃는 눈은 눈 아래 피부색을 읽어야 해서 **가장 큰 품질 위험**(눈 밑 그림자·무늬가 있으면 어색).
- 표정 둘이 섞일 때는 기준점 이동값을 비율로 섞는다. 다섯 표정 모든 짝의 중간 모양을 눈으로 확인할 것.

### 입술 떨림(울먹임)
입 세 점을 작고 빠르게, 일정하지 않게 위아래로 흔든다. 앙 다문 입과 구분된다.

### 눈물(울먹임)
눈꼬리 두 점 + 아랫꺼풀 가운데로 아랫꺼풀 곡선을 계산, 그 곡선 위 바깥쪽 1/3에 **곡선 기울기를 따라** 맺힌다(아랫꺼풀과 수평으로 붙이지 않는다). '진할 때'(연타 더 진하게)에는 볼을 타고 한 줄기 흘러내리고 끝에서 옅어진다.

### 땀방울 (1~3개)
- 맺힘 → 살짝 부풂 → 짧게 흘러내리며 늘어짐 → **움직이는 도중에** 옅어짐. 제자리에서 사라지면 수포처럼 보여 징그럽다.
- 물방울로 읽히게 작은 반사광. 최대 3개(많으면 징그럽다).
- 1개 = 당황·황당, 2~3개 = 부끄러움·곤혹. 처음 위치는 얼굴 부위 기준 관자놀이·이마 근처에 자동, 사용자가 끌어 옮길 수 있게.

### 만화 기호
💢 · 눈물 · 하트 · 반짝이 등. 이모지가 아니라 **코드로 그린 단순 모양**(기기마다 모양이 달라지지 않고 영상에 똑같이 담김). 얼굴 점 기준으로 놓이고 캐릭터 움직임을 따라간다. 표정마다 골라서 가감.

## 6. 쓰는 곳 (영역마다 · 기존 칸에 추가)
- **3. 몸체 움직이기**: 평소 표정 [없음/표정] + 세기.
- **4-1 연속 움직임**: 이 영역이 움직이는 동안 지을 표정 + 세기, 움직임 박자에 맞춰 살짝 오르내림. 예: '↖↗ 양쪽 위로' + 부끄러움 60% = 몸을 흔들며 부끄러워하는 캐릭터.
- **4-2 터치 움직임**: 표정 반응과 맞은 자리 표시는 **별개 반응**(둘 다 켤 수 있음).
```
☐ 표정 바꾸기   [얼굴 1 · 화남 ▾]  세기 ━━●━ 70%   [다듬기]
    ☐ 연타 반응   ( ) 더 진하게   ( ) 다른 표정으로 [놀람 ▾] [다듬기]
☐ 맞은 자리     [빨개짐 / 갈라짐]
```
- **연타 반응**은 먼저 켤지 정한다. '더 진하게' = 세기 +10~20% + 표정별 '진할 때' 추가 효과(울먹임 → 눈물이 흘러내림, 부끄러움 → 땀 하나 더, 화남 → 💢 커짐 등). '다른 표정으로' = 드롭다운에서 고르고, 그 표정도 [다듬기]로 같은 창에서 조절.
- 연타 기준(예: 3초 안에 5번)은 기본값으로 두고 세부 설정에 숨긴다. 연타가 멈추면 천천히 원래 표정으로.

### 겹치는 규칙
최종 표정 = 기본(몸체 평소 · 연속) + 터치 반응.
- 같은 표정이면 더한다(상한 100%). 반응은 1~2초에 걸쳐 원래로 돌아온다.
- 다른 표정이면 터치 반응이 잠깐 앞서고(그동안 기본 표정은 옅어짐) 끝나면 기본으로 돌아온다.
- 터치 세기(지금 움직임 반응이 쓰는 hitPower)를 반영, 연타는 누적.
- 몸 움직임(흔들림·반발)은 표정과 별개로 계속된다.

## 7. 홍조 · 맞은 자리 표시

### 뺨 위치 추정 (입력 없이, 눈·입 값으로 최대한 해석)
- 두 눈 너비 비율 → 고개가 돌아간 정도. 좁은 쪽 뺨은 좁게, **눈 바깥 끝을 넘지 않게**.
- 두 눈을 이은 선의 기울기 → 고개 기울기, 뺨 타원도 같이 기울임.
- 눈~입 거리 → 얼굴 크기. 뺨 높이는 눈 아래~입꼬리 사이.
- **코 자리**: 입 가운데에서 눈 선과 직각으로 위로 그은 선. 양쪽 홍조가 이 선을 넘지 않게.
- **그림체 추정**: 눈 크기와 눈~입 거리 비율 → SD체면 뺨 크고 둥글게·낮게, 실사체면 작게·광대 쪽 높게.

### 홍조 스타일 (세 가지, 기본값은 그림체 추정으로)
| 스타일 | 어울림 |
|---|---|
| 그라데이션 | 모든 그림체 |
| 그라데이션 + 섬세한 빗금 | 실사체·일반 일러스트 (사용자 참고 그림 '맙홍조1' 느낌) |
| 만화 빗금 `////` (굵고 또렷 3~5줄) | SD체 |
- **섬세한 빗금**: 그라데이션 위에 아주 가늘고 짧은 선 여러 개, 가운데에 몰리고 바깥으로 옅고 짧아짐, 홍조보다 조금 진한 붉은색·낮은 불투명도, 길이·간격 조금씩 들쭉날쭉(손맛). 굵기·길이는 얼굴 크기에 맞춤.
- **귀도 붉게**(홍조 세부 옵션): 귀 선을 따라 같은 스타일로. 두께는 얼굴 크기로 자동.

### 질감 — 매끈하면 안 된다 (사용자 지적)
그라데이션만 얹으면 피부가 금속·플라스틱처럼 보인다.
1. 넓고 옅은 얼룩(큰 노이즈) + 고운 입자(작은 노이즈)를 겹친다. 입자는 그림 해상도에서 셰이더로 계산(얼굴 지도 128px로는 거침).
2. 외곽을 완전한 타원이 아니라 살짝 울퉁불퉁하게.
3. 분홍을 덧칠하지 말고 **피부색에 붉은 기운을 곱하듯 물들인다** → 음영 유지, 선화가 분홍으로 뜨지 않음. 사실감에 가장 크게 작용.
- 빨개짐 · 귀 붉어짐에도 같은 처리.

### 맞은 자리 표시 (4-2, 영역마다)
- **빨개짐**: 누른 자리에 붉은 기운이 번졌다가 약 1초에 빠짐, 연타하면 진해짐, 그림 변형과 함께 움직임. 질감 처리 동일.
- **갈라짐**: 누른 자리에서 갈라지는 선이 생겨 잠시 남았다가 사라짐, 여러 번 치면 늘어남(개수 상한). 선 색은 그 자리 그림보다 어둡게 자동. 이름은 '빨개짐'과 짝을 맞춰 '갈라짐'.

## 8. 기술 구조
- **얼굴 지도 텍스처 1장**: 얼굴 기준점 이동을 앱(CPU)이 작은 지도(예: 128×128, RG = 이동량, B = 붉은 정도)로 계산해 매 프레임 올린다. 셰이더 텍스처 슬롯 7/8 → **8/8 사용**. 얼굴 수·점 수와 무관하게 1장.
  - 슬롯을 남겨 둘 이유는 '영역 12개 초과'(영역 데이터 텍스처)뿐. 그때는 얼굴 지도와 영역 데이터를 **한 장에 나눠 담는다**(얼굴 수를 줄여도 슬롯은 안 돌아온다). WebGL2 기기는 슬롯 16개.
- 영역별로 늘어나는 uniform은 표정 번호·세기 정도(한계 안).
- 고운 노이즈·빗금·만화 기호·땀·눈물·갈라짐 선은 셰이더 또는 터치 이펙트 층(3-F, touchfx)에 그린다. 기호·땀·갈라짐은 CPU 쪽 변형 계산(cpuDeformation)으로 기준점의 이동을 구해 따라가게 한다.
- 영상 · 움짤 · 플레이 화면 녹화 · 터치 파일에 모두 그대로 담긴다(같은 그리기 경로).
- 저장 형식: 얼굴(부위 좌표, 표정 다섯 개 값)과 영역별 표정 설정을 프로젝트에 추가. 옛 프로젝트는 얼굴 없음으로 열린다.

## 9. 위험 · 한계
- 단순한 얼굴(점 눈, 선 입)에서 가장 자연스럽다. 정교한 얼굴일수록 효과가 약하고 어색할 수 있다.
- 웃는 눈의 눈 밑 피부색 처리(§5).
- 눈썹이 앞머리에 가려졌거나 머리카락과 붙어 있으면 눈썹 변형이 머리카락도 함께 휜다(넓은 범위로 완화).
- 폰에서 선 따라 그리기 입력 피로(확대경으로 완화, 필요한 부위만 요구).

## 10. 구현 순서 제안 (작게 나눠 사용자 확인)
1. 2번 섹션 틀(테두리 상자 · 적용 체크 · 흐림/강조색) + 눈 깜빡임 이동 + 얼굴 목록
2. 얼굴 지도 텍스처와 유동화 엔진 + 입 3점 · 눈썹 선 입력 → 표정 상세 세팅 창(조절 막대) 
3. 프리셋 다섯 개 값 맞추기(눈으로)
4. 4-1·4-2·몸체의 표정 칸, 겹치는 규칙, 연타 반응
5. 홍조(뺨 추정 · 질감 · 세 스타일 · 귀) · 맞은 자리(빨개짐 · 갈라짐)
6. 땀방울 · 눈물 · 입술 떨림 · 만화 기호
