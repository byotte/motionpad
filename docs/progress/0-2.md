## 변하지 않은 것 (회귀 없음)
- 저장 파일: 원본과 바이트 단위로 같다(포맷 v2, 이미지·설정 동일).
- 선택 결과: 타원·마술봉·간략 올가미 픽셀 수 동일.
- 시계 고정 스크린샷(화면 6종 × 시작/편집, 테마 3종): 원본과 0.00% 차이.
- 페이지 오류 0건.

## 사용자가 느낄 변화
- 몸체로 지정한 영역은 이제 원래 경계값(기본 8·9)을 그대로 쓴다. 전에는 몸체 테두리가 강제로 날카로웠다. 필요하면 슬라이더로 줄이면 된다.
- 옵션을 만진 뒤 그림을 누르면 반응을 미리 볼 수 있다. 다시 선택 작업을 하려면 도구 버튼을 한 번 누르면 된다.

## 남겨 둔 것
- 프로젝트 불러오기·삭제의 confirm() 창은 REVIEW에서 3단계(기본 대화창 제거) 대상이라 그대로 둔다.
- 마스크 아틀라스 텍스처는 여전히 통째로 올린다(영역 하나만 바뀌어도). 측정상 지금 남은 비용의 주인은 바뀐 영역의 dilateMask·블러라 우선순위가 낮다.
