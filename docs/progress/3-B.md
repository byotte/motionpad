# 3-B 단축키 (PC)

포토샵·클립스튜디오에 익숙한 키로 맞췄다. `src/js/shortcuts.js`.

| 키 | 동작 |
|---|---|
| B · E · W · L · M · V · H | 붓 · 지우개 · 마술봉 · 올가미 · 도형 · 이동 · 화면 이동 (Space 누른 채 끌기는 그대로) |
| Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+S · Ctrl+O | 프로젝트 저장 · 프로젝트 열기 |
| N · Ctrl+J · Delete(Backspace) | 새 영역 · 복제 · 삭제(확인창 거침) |
| Enter · Esc | 마술봉·외곽·올가미·축 지정 '적용/완료' · 미리보기 취소 |
| [ · ] | 붓 굵기 |
| + · - · 0 | 화면 확대 · 축소 · 100% |
| P | 플레이 |

- 글자를 입력하는 중, 대화창이 떠 있을 때, 플레이 화면에서는 동작하지 않는다(대화창의 Enter·Esc는 원래대로 버튼·닫기).
- Esc는 '그만두기'(편집 전으로 되돌림)에 묶지 않았다. 작업이 날아갈 수 있어서.
- 도구·버튼에 마우스를 올리면 이름 옆에 키가 보인다(예: "붓 (B)").
- 폰·터치에는 영향 없음.

## 확인
- 도형 키 → 그리기 → Ctrl+J 복제 → Ctrl+Z / Ctrl+Shift+Z → B·] 붓 굵기 → = 확대 → Delete 확인창 → Esc 닫힘 → W·그림 누르기·Enter 적용 → 이름 칸에 'bmw' 입력해도 도구 그대로 → Ctrl+S 파일 저장 → P 플레이. 오류 0, 브라우저 기본창 0.
