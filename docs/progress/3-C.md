# 3-C 안내줄 (안내 문구를 한 곳으로)

사용자 결정(2026-11-13): 캔버스 바로 아래 전용 한 줄.

- 상태 문구(`#status`)를 확대·돋보기 버튼 줄에서 떼어 캔버스 바로 아래 **안내줄**(`.guideLine`)로 옮겼다. 앞에 작은 i 아이콘, 글씨 12px, 옅은 포인트색 바탕.
- PC: 한 줄. 넘치면 '…', 마우스를 올리면 전체 문구. 폰: 두 줄까지(폰은 캔버스 높이가 고정이라 줄이 늘어도 그림이 흔들리지 않는다).
- 도구를 고르면 "○○을 선택했습니다. (다음에 할 일)" 꼴로 통일(붓·지우개·마술봉·올가미·도형·이동·화면 이동). 폰에서 아이콘만 남은 도구의 이름을 여기서 알린다(2-E 남은 일).
- 폰: 아래 버튼 줄(되돌리기·확대·돋보기·손가락 보정·영역선)을 한 줄에 맞추려고 아이콘 버튼 폭을 28px로 줄였다(390px 폰 기준 한 줄, 폴드 겉화면 344px는 영역선만 다음 줄).
- 그대로 둔 것: 마술봉·외곽 선택 막대 안의 단계 표시(1. 누르기 → 2. 범위 조절)와 축 지정 안내. 그 도구를 쓰는 동안 바로 옆에서 봐야 하는 단계 표시라 막대에 남겼다.

## 확인 (`run.js`, 3-B 결과물과 비교)
- 오류 0, 저장 왕복 동일, 동작 시험 5종 통과, 선택 방식 시험 9단계 통과.
- 화면 변화는 안내줄이 생기며 캔버스가 조금 줄어든 것(의도). 그래서 시험 스크립트가 같은 화면 좌표로 그린 영역의 위치·넓이가 미세하게 다르다(선택 시험 넓이 7153 → 7194, 저장 파일 +45바이트). 선택 엔진 결과(마술봉 5874, 외곽 2826)는 같다.
- 성능 수치 차이는 헤드리스 측정 잡음 범위(같은 결과물끼리도 ±10% 안팎).
