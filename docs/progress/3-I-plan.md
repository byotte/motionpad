# 3-I 옵션 구성 정리(몸체 지정 = 완장) — 합의된 구성, 구현 전

모양(색·글자·선)은 건드리지 않는다. 그건 `docs/DESIGN-RULES.md` 단계에서 한 번에. 저장 형식 불변.
시안(참고용, 색·크기는 확정 아님): `img/3i-body-mock-phone.png`, `img/3i-body-mock-pc.png`.

## 1. 영역
- 영역 목록(지금 그대로) · 영역 이름 · 잠금 · **몸체 지정 버튼(완장)** · ▸경계 · ▸고정점과 가이드.
- **'범위 다듬기' 버튼 삭제**(붓 도구로 바꿔 줄 뿐이라 도구줄과 중복).
- 완장 버튼: 몸체가 아닌 영역 = "이 영역을 몸체로 지정" + 안내("지금 몸체: 이름" / 몸체 없음). 몸체 영역 = "몸체 지정 해제" + **자동 크롭**(다른 영역을 몸체 안으로 제한) 스위치.
- '▸움직일 몸체 지정' 묶음은 없앤다(내용이 위와 2로 나뉜다).

## 2. 몸체 움직이기
- 첫 묶음(대상): **움직임 켜기**(이전 '전체 움직임 켜기') 와 **[이미지 전체 / 몸체]** 고르기를 한 줄에. '몸체'일 때만 그 아래 **몸체 경계 흐림**.
  - [이미지 전체 / 몸체] = 기존 '배경 제외' 값(`base.exclude`) 그대로. 몸체 = 켬, 이미지 전체 = 끔.
  - 몸체 영역이 없으면 '몸체'는 고를 수 없고 "1. 영역에서 몸체로 지정해 주세요" 안내. 완장을 채우면 자동으로 '몸체'.
  - 움직임을 끄면 고르기와 아래 효과는 흐리게(감추지 않는다).
- 둘째 묶음(효과): 부드러운 호흡 · 미세 흔들림 · 조명 숨쉬기.
- 두 묶음은 실선 상자로 나눈다(제목 없음). 선 모양은 디자인 규칙 단계에서 확정, 그 전에는 기존 선.

## 구현 순서 (작게 나눠 커밋)
1. 1. 영역: 범위 다듬기 삭제, 완장 줄, 자동 크롭 이동, basePanel 제거.
2. 2. 몸체 움직이기: 대상 줄·경계 흐림 이동·두 묶음.
3. 검증 도구(scenes.js·schema_check 등)의 id 갱신, 회귀, 기록.
