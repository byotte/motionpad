- A5 없는 파일 두 개(manifest·sw.js) 참조: 그대로 둠(동작에 지장 없음). 아래 '설명' 참고.
- C18 화면 이동 버튼 위치: 지금 자리 유지(사용자 결정).
- B4-5 영상에 배경음악: 디자인 확정·실기기 시연 뒤 별도 단계(사용자 결정).

## 확인 (모두 결과물 `motionpad.html`을 실제로 눌러 봄)
- 스페이스바: 도구 버튼을 마우스로 누른 직후 150% 확대 상태에서 스페이스+끌기 → 화면 80·40px 이동, 영역 0개. 그 뒤 붓 그리기 정상. 그림 밖에서 버튼 초점 + 스페이스 → 버튼 눌림 유지.
- 되돌리기: 몸체 호흡 35 → 80 → 되돌리기 35(표시 35%) → 다시 실행 80. 움직임 켜기·몸체 경계 흐림(몸체 지정은 유지됨)·선택 영역 투명도·색도 같은 방식으로 통과.
- 저장 창(가짜 저장 창을 끼워 확인): 첫 저장에 창 1번, 두 번째 저장은 창 없이 같은 파일, 다른 이름 저장 뒤 프로젝트 이름이 파일 이름을 따라감, 취소하면 "저장을 취소했습니다", 새 그림을 연 뒤에는 다시 물음. 실제 저장 창이 뜨는 모습은 실기기(PC 크롬)에서 볼 것.
- 큰 그림: 22,090,791바이트 그림을 넣고 저장 → 파일 안 그림 길이가 원본과 일치(줄이지 않음).
- 영상: 직접 입력 600 → 600×750, 세로 500 → 400×500, 비율 유지 끄고 640×360 → 실제 저장한 영상이 640×360(ffprobe). 화질 이름표는 0~16 낮음, 17~49 보통, 50~83 높음, 84~100 최고(슬라이더 아래 글자 위치와 맞춤). PC·폰 화면 확인.
- 눈: 4개를 찍어 적용 → 저장 파일에 4개, 다시 열어도 4개(✓), 눈 3 제거 → [1,1,빈칸,1]. 빈 프로젝트 저장은 예전과 같은 [null,null]. 플레이 화면 6초 동안 오류 0.
- 아이콘 색: 그림이 화면을 채우는 세 경우(크림색·회갈색·파란 하늘)에서 아이콘 바탕이 뒤 색을 따라가고 글자색이 밝기에 따라 바뀜. 그림 밖 여백에 있을 때는 어두운 회색.
- 전체 비교(`run.js` 고치기 전 → 뒤): 저장 왕복 동일(101,049바이트 그대로), 선택 결과 동일(마술봉 5874, 외곽 2826), 화면 48장 가운데 달라진 것은 영상 창 2장(의도)과 `roundtrip-reopened`·`select-all-zones`·`select-outline-draft` 3장(0.3~0.7%). 뒤의 3장은 그림을 나란히 놓고 봤고, 안내줄 문구("렌더 품질을 자동으로 조정했습니다"가 뜨는 시점)와 숨쉬는 움직임의 순간 차이였다(3-I 기록과 같은 종류).
- `schema_check` 완전히 같음, `shape_check` 11단계·`selop_check` 9단계 통과, 오류 0, `build --check` 일치. 성능 수치는 잡음 범위.

## 시험 도구 변경
- 저장 창은 자동 조작으로 다룰 수 없어, 저장을 쓰는 도구 8개(`run.js`, `schema_check.js`, `shape_check.js`, `selop_check.js`, `grid_cost.js`, `frame_cost.js`, `hires_check.js`, `quality_check.js`)는 시작할 때 저장 창 기능을 꺼서 내려받기 경로로 저장한다.

## 실기기에서 볼 것(추가)
- PC 크롬에서 저장 창이 뜨고 고른 폴더에 저장되는지, 폰에서는 내려받기로 저장되는지.
- 큰 그림(20MB 이상)을 폰에서 열고 저장할 때 느려지거나 멈추지 않는지.
- 플레이 화면 아이콘 색이 실제 그림들에서 거슬리지 않는지.
