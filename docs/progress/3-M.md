# 3-M PC 검수 반영 (2026-11-14)

사용자가 PC에서 써 보고 준 목록을 반영했다. 폰 검수는 이 단계가 끝난 상태에서 한다.

## 조작 방식이 바뀐 것
| 항목 | 전 | 후 |
|---|---|---|
| 마술봉·올가미 '적용' | 미리보기 → '적용'을 눌러야 영역이 됨 | 고르는 즉시 영역에 반영. 선택 범위를 다시 조절하면 방금 반영을 걷어내고 새로 반영(되돌리기 기록은 한 칸). '취소' = 방금 선택만 걷어냄 |
| 되돌리기 | 적용 전 초안은 되돌리기와 무관 | 늘 '마지막에 한 일'이 취소됨. 나눠 그리는 올가미는 마지막 구간부터 |
| 나눠 그리는 올가미 | '적용' | '닫아서 완료'. 도구를 바꾸면 그리던 것을 닫아 반영 |
| 올가미 선택 범위 | 눈금이 0~10에 몰려 그 뒤는 전부 '둘러싼 범위 전체' | 그림마다 점수 범위에 맞춰 막대 전체에 고르게 폄(0은 예전 기준 그대로). 자잘한 점(가장 큰 덩어리의 2% 미만) 제거 |
| 축 지정·축 추가·가이드 선 | 캔버스 전체 화면으로 바뀌고 '완료' | 그 자리에서 바로. 축 지정은 누를 때마다 옮겨짐, 같은 버튼을 다시 누르면 하던 도구로 |
| 지정 뒤 '이동' 도구가 켜지던 문제 | 축 추가·가이드 선·흐름 방향 지정 뒤 이동 도구로 바뀌어 끌면 영역이 밀림(사용자가 본 버그의 원인) | 하던 도구로 돌아감 |
| 새 영역 | 늘 붓으로 바뀜 | 쓰던 도구 유지(그리는 도구가 아닐 때만 붓) |
| 터치 테스트 | 옵션을 건드려야 켜짐 | 안내줄 오른쪽 '터치 테스트' 버튼(T) |
| 새 영역 이름 | 도구마다 다름(외곽 선택·마술봉 2·영역 3) | 모두 '영역 N' |

## 움직임 옵션
- 3-1 연속 움직임 = 늘 방향·세기·속도 셋(프리셋에 따라 바뀌지 않음). 방향은 터치 방향과 따로 저장(`autoAxis`, 예전 파일은 터치 방향에서 정함).
- '세부 · …' → '기타 움직임 효과', 부분 호흡 → 호흡, '그림에서 흐름 방향 지정' 삭제.
- 바람·흐름 방향 = 돌리는 다이얼(값은 그대로 각도).
- 상한: 비틀림 35→60, 흐름 40→65, 바람 강도 100→165(표시는 0~100%), 바람 속도 3→5. 예전 값은 그대로 같은 세기.
- 조명 숨쉬기: 밝기가 ±1%도 안 변해 체감되지 않음 → 화면에서 빼고 늘 0.
- '외곽까지 흔들기' → '빈자리 채우기'.

## 몸체 지정 뒤 테두리 자국
몸체 그림을 선택 모양 그대로 얹고 빈자리는 2칸 넓게 메워서, 가만히 있어도 그 사이 띠에 메운 색이 비쳤다. 얹는 그림을 3칸(+경계 흐림만큼) 넓혔다(`masks.js updateBaseTextures`). 외곽 흔들기에는 2-M에서 이미 넣은 규칙.

## 화면·메뉴
- 판 번호 '1.0', 머리줄에 프로젝트 이름(폰형은 파일 메뉴 맨 위), 파일 ▸ 프로젝트 닫기(시작 화면으로, 자동 저장본은 '이전 작업 이어하기'로 남음).
- 메뉴: 펼친 채 옆 메뉴로 옮기면 따라 펼쳐짐, 화면 밖으로 나가지 않게 자리 맞춤, 단축키 표기(PC만), Ctrl+Shift+S·Ctrl+E 추가.
- 설정: '선택 영역 표시'는 폰형만, '버전 정보' 추가.
- 대화창: '닫기'만 있던 아랫줄 제거(소리·설정·선택 영역 표시·임시 보관·영역 메뉴). 영상 창은 버튼이 있어 아랫줄 유지, '닫기'만 뺌.
- 영상 창: 비율 = 원본 비율·9:16·3:4·1:1, 화질 숫자만, 두 가지 방법(자동으로 저장 / 직접 터치하며 녹화 → '플레이 화면에서 녹화' 버튼)으로 묶음.
- 소리 창: 고르기 옆에 '파일 불러오기', 효과음도 파일로(2MB 이하, 프로젝트에 함께 저장: `sfx`, `sfxName`).
- '기기에 보관한 프로젝트' → '브라우저에 임시 보관된 프로젝트'(예전 버전의 '기기에 저장' 복구용). 겹치는 '그림으로 시작·프로젝트 열기' 버튼 제거.
- 조절 막대 숫자: 모두 표시·강조색 통일. 영역 목록 칸마다 흐린 테두리. 축 버튼 넷 한 줄. 영역 관리 버튼은 도구 바로 뒤.
- 눈 깜빡임 창: 왼쪽 그림·오른쪽 옵션, '눈 감은 모습 보기', '마지막 보호 획 취소' 삭제(되돌리기와 같음), 버튼을 공용 규칙으로.
- 플레이 화면: 아이콘 상자 제거·굵게, 플레이어 접기 '_', 효과음 버튼 ▶/❚❚. 터치 표시는 녹화 중에만, 모양 셋(물결 고리·작은 점·반짝임), 크기 절반 이하.

## 저장 형식
그대로(v2). 더해진 것: 영역 `autoAxis`, 파일 `sfx`·`sfxName`. `editorVersion` = 1.0.0. 없는 파일도 그대로 열린다.

## 시험 도구
'적용' 버튼이 없어져 기다리는 신호를 바꿨다: `#wandbar`·`#outlineControls`의 `data-ready="1"`.

## 사용자 확인이 필요한 것
- 버전 정보의 제작자·연락처 문구, 내장 녹음 효과음 4개(`src/sfx`)와 샘플 그림의 출처.
- 판 번호 표기, 효과음 ▶/❚❚ 방향, 터치 표시 모양 기본값.
