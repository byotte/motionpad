# 3-N PC 2차 피드백 + 가장자리 붙잡기 (2026-11-15)

## 움직임
- **가장자리 붙잡기**: 그림 테두리의 픽셀은 움직이지 않고 안쪽 4.5% 구간에서 서서히 풀린다(`shaders.js` edgePin). 테두리에 닿아 잘린 부위를 당겨도 그림 밖이 드러나지 않고 늘어나며 따라온다. 영역 변형·몸체 호흡(몸체 대상)·빈자리 채우기 레이어 모두에 적용. 그림 전체 호흡(정점 이동)은 그대로.
- **부드러운 호흡 다시 만듦**: 위아래로 늘었다 줄던 것 → 가슴(중심)이 좌우로 부풀고 그 위쪽이 살짝 들린다. 중심은 거의 안 움직이고 멀수록 크다. 중심 = 몸체 영역의 가슴께(`u_bodyCenter`, 몸체가 없으면 그림 가운데 조금 위).
- 두 손가락 확대·이동: 화면 좌표로 계산(그림 좌표로 재서 튀던 문제), 터치 on 상태에서도 가능. 도형 도구에서 도형을 고른 때만 도형 다듬기.

## 화면
- 캔버스 아래 줄: 돋보기·손가락 보정·영역선·터치 = 켜고 끄는 상자(`.tog`). '터치 테스트' → '터치 on/off', 영역선 옆. 손가락 보정은 터치가 되는 기기에서만(`any-pointer:coarse`).
- 폰형: 안내줄을 눌러 접기·펴기(꺾쇠 표시, 기억). 마술봉·올가미로 고른 뒤에도 교체·더하기·빼기가 보이게 옵션 줄 두 줄.
- 눈 깜빡임 창: 확대 범위도 되돌리기에 포함, − 100% + · 마우스 휠 · 스페이스+끌기, 앞머리 영역 덧칠이 진해지지 않음, '초기화'·'앞머리 영역'으로 이름 변경. 폰형은 윗줄 한 줄(옆으로 밀기), 그림은 위에 붙어 있음(sticky).
- 닫기(×)는 선 두 개로 그려 상자 가운데. 새 영역·복제·삭제 버튼 바탕 없음.
- '프로그램 정보'(정보 · Tip · 단축키 (PC)), '임시 보관된 프로젝트'.
- 영상 창: '연속 움직임 녹화'·'터치 움직임 녹화', 창에서 넘어간 녹화는 고른 길이만큼 찍고 저절로 저장, '저장 완료'·이어짐 안내 삭제.
- 움짤 예상 용량: 그림 전체가 움직이면 프레임마다 거의 전부가 바뀌는 것을 반영(0.07 → 0.6 바이트/픽셀·프레임), 한 번 저장하면 실제 크기로 보정. '영상보다 훨씬 큽니다'는 실제로 1.5배 넘을 때만.

## 확인
- `shape_check`·`selop_check` 오류 0건, `token_check` 0건. 눈 창은 확대 뒤 네 점 찍기·되돌리기·휠 확대까지 자동 조작으로 통과(사용자가 본 '두 점 뒤 멈춤'은 재현하지 못함).
- 가장자리 붙잡기·호흡의 느낌, 두 손가락 조작은 실기기 확인 필요.

## 3-O 빈자리 메우기 색 번짐 (2026-11-15)
- 원인: 메울 색을 구멍 바로 옆(몸체 테두리에 붙은 탁한 띠)에서 가져와 그 색이 안쪽으로 번졌다(초록 한가운데 회색 줄).
- 고침(`masks.js buildBackgroundPlate`): 메울 색은 구멍 바깥 3칸을 건너뛴 곳에서 가져온다. 띠 자체는 원본 그대로 둔다. 조각 붙이기도 띠 대신 깨끗하게 메운 색을 재료로 쓴다.
- 몸체는 4칸 넓게 파서 윤곽 자국까지 메우고, 얹는 그림은 5칸(+경계 흐림) 넓게 덮는다 → 가만히 있을 때는 수정 전과 같다(화면 비교: 다른 픽셀 수 3267 → 3322, 모두 영역 자체의 약한 호흡 때문).
- 빈자리 채우기(꼬리 등)는 2칸·3칸 규칙 그대로, 색 가져오는 곳만 바꿈.
- 선택 영역 표시(색·투명도): PC·폰 공통으로 설정 메뉴에서만 연다. 옵션 패널 아래 칸은 없앰(사용자 결정). 앞서 'PC에서는 메뉴 숨김'은 스타일 우선순위 실수로 처음부터 적용되지 않았다.

## 3-P 빈자리 메우기: 가까운 색 잇기 (2026-11-15)
- 3-O 뒤에도 회색 줄이 남음(사용자 그림). 원인: 부드럽게 채우기(넓은 평균)가 밝은 색을 어두운 쪽으로 번지게 함.
- 고침(`masks.js buildBackgroundPlate`): 가장자리에서 12칸(850px 기준)까지는 가장 가까운 깨끗한 픽셀의 색을 그대로 잇고, 46칸까지 서서히 부드럽게 채운 색으로 넘어간다. 그 위에 조각 붙이기가 이어서 돈다.
- 사용자 화면 조각(3배 확대)으로 재현해 전·후 비교: 드러난 자리의 회색 띠가 없어지고 초록 표지판이 이어져 보임. 가만히 있을 때는 그대로.
