# B단계: 도움말 동그라미(ⓘ) → 안내줄 (2026-11-17)

시작 전 지점: 로컬 태그 `before-B`. 문구는 `B-help-draft.md` 초안 그대로(사용자: 쓰면서 이상하면 알려 줌).

## 어떻게 뜨는가
- **PC**: 항목(이름·막대·버튼이 든 한 줄)에 마우스를 0.15초 올리면 아래 안내줄에 짧은 한 줄이 뜨고, 떠나면 원래 안내로 돌아간다. 키보드로 초점이 가도 같다.
- **폰**: 항목 이름을 누르거나 그 항목의 막대·버튼을 잡는 순간 뜬다. 5초 뒤 또는 다른 곳을 누르면 원래 안내로. 안내줄을 접어 둔 사람에게는 잠깐 펴서 보여 주고 다시 접는다.
- **이름을 누르면 고정**(PC도): 긴 설명이 있는 항목은 끝에 '더 보기' → 누르면 안내줄 위로 펼쳐진다(그림 위에 겹침, 그림을 밀지 않음). 다른 곳을 누르면 접힌다.
- 대화창 안 항목은 그 창 아래 안내 칸에(표정 창 `#exprHint`, 눈 창 `#blinkHint`, 영상 내보내기·소리 창은 맨 아래에 새로 만든 한 줄 `.dlgHelp`, 비어 있을 때 기본 문구 "항목에 마우스를 올리면 설명이 나옵니다." / 폰 "항목 이름을 누르면 설명이 나옵니다.").
- **그림에서 자리를 찍는 도구(입·눈썹·귀·축·가이드 선)가 켜져 있는 동안은 띄우지 않는다.** 찍기 안내가 바뀌는 순간 떠 있던 설명도 걷힌다.

## 구조
- 설명은 '잠깐 얹히는 층'이다: 안내 요소 옆에 같은 칸으로 겹친 `.helpLayer`(`dialogs.js` `showHelp`·`clearHelp`). `setStatus`는 원래 안내 층만 바꾼다(그대로).
- HTML에는 동그라미 대신 표시 `<i class="helpMark" data-help-short data-help>`만 두고, 시작할 때 그 항목 줄로 옮긴다(`data-help-short`·`data-help`, 이름 글자는 `.helpName`). 긴 설명이 없는 항목은 '더 보기'가 없다.
- 없앤 것: 동그라미 24개, 말풍선 `#localHelp`, 관련 CSS. 새 설명은 터치 스위치(`편집 | 만져 보기`) 하나.
- `scenes.js`의 'help' 장면은 마술봉 '선택 범위' 이름을 누르는 것으로 바꿨다.
