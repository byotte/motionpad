# C단계: 부위 고르기 + 간단 카드 (2026-11-17)

시안: `img/C-card-mock-{pc,phone}.png`. 사용자: "우선 다 반영, 판단은 그 후". 시작 전 지점 = 로컬 태그 `before-C`.

## 화면
- 처음 온 사람은 **간단히**(오른쪽 칸·폰 그림 아래에 카드만). 카드 오른쪽 위 `자세히 ▸` → 지금 패널 전체, 맨 위 `◂ 간단히`. 상태는 브라우저에 기억(`localStorage motionpad-panel`).
- 카드 상태: ① 영역 없음(안내 + `눌러서 고르기(마술봉)`·`둘러 그리기(올가미)` + 전체 숨쉬기) ② 새 영역, 부위 아직("이 부분은 무엇인가요?" + 부위 칩) ③ 부위 정함(부위 칩 / `크기 [약·중·강(·직접 맞춤)]` + 방향 긋기 / `저절로 [끔·느리게·보통·빠르게]`) ④ 아무것도 안 고름(영역 칩 + 전체 숨쉬기 + 얼굴 넣기). 몸체 영역을 고르면 부위 칩 없이 "몸체는 ‘전체 숨쉬기’가 맡습니다."
- **시안에서 바꾼 한 가지**: '저절로 [켬·끔]'과 '빠르기'를 한 줄로 합침(PC 칸 300px에서 4줄을 넘지 않게). 끔 = 가만히, 빠르기를 고르면 그 빠르기로 저절로.
- 폰 간단히: 그림이 남은 높이를 채우고 카드는 내용만큼(최대 45dvh). 390×844에서 그림 칸 높이 354 → **448px**, 344×882에서 370 → **429px**. 자세히는 전과 같다(묶음 4의 '패널이 남은 높이를 채움'). 높이 나누기는 responsive.css 세로 묶음 두 줄.

## 값 (한 벌)
- 부위 칩 = 움직임 프리셋(`preset`). 볼=jelly, 가슴·배=breathing(세기를 볼 탄성 수준 30으로 올림), 머리카락=wind, 꼬리=tail, **귀=ear(새: 부드러운 반응 바탕, 축 켬, 끄는 쪽으로)**, 옷자락=scarf, 기타=soft. 값이 flow·custom이면 '흐름·물결'·'직접 설정' 칩이 하나 더 보인다. '자세히'의 프리셋 고르는 칸도 같은 이름으로 바꿨다.
- 새 영역 속성 `level`('s'·'m'·'l', ''=직접 맞춤). 옛 파일은 ''. 크기는 프리셋 값 × 0.6/1/1.5(`strength`·`autoStrength`·바람·호흡·물결·흐름·비틀림, 속성표 범위로 자름). '자세히'에서 이 값들을 손대면 `level=''` → 카드에 '직접 맞춤'.
- 저절로 판정은 `autoOn` 한 곳(auto 켬 또는 바람·흐름·물결·비틀림 > 0 또는 호흡 > 8). 끄면 직전 값을 실행 중에만 들고 있다가 다시 켜면 되살림(없으면 프리셋 × 크기, 연속 움직임이 없는 부위는 auto 켜고 위아래). 빠르기 = 프리셋 빠르기 × 0.6/1/1.6(바람 `windSpeed`, 호흡 `breathSpeed`, 그 밖 `autoSpeed`), 표시는 값에서 읽는다.
- 부위를 고르면: 프리셋 값으로 덮음(자세히에서 손댄 값이 있으면 확인창) · 이름이 '영역 N'이면 부위 이름(같으면 '볼 2') · 소리 없이 한 번 튕김 · 터치 스위치 켬. 머리카락·꼬리·옷자락은 바로 가이드 선 도구가 잡히고 "붙어 있는 곳에서 끝까지 한 번 그어 주세요. 건너뛰어도 됩니다."
- **부위를 묻는 것은 이번 실행에서 새로 만든 영역뿐**(프로젝트를 열 때 있던 영역은 '직접 설정' 칩으로 보임).
- 교체(사용자 결정 4: 알리기만): 이미 있던 영역의 모양이 바뀌면 "‘볼’의 모양을 바꿨습니다. 새 부위를 만들려면 ‘+ 다른 부위’를 누르세요."
- 카드 그리기는 `renderCard` 하나(updateUI·updateValues가 부름). 되돌리기·영역 바꿔 고르기·열기·삭제 뒤 따로 챙길 곳이 없다.
- 효과음 열(부위별 효과음)은 F단계에서 잇는다.
