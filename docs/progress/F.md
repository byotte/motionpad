# F단계: 손맛 — 영역마다 효과음 · 폰 진동 · 가끔 짓는 표정 (2026-11-17)

## F-1 영역마다 효과음
- 영역 속성 `sfx`(효과음 id, `''` = 소리 창의 전체 설정을 따름). 옛 파일은 `''`.
- '자세히' 4-2 맨 위 `효과음` 고르는 칸(첫 칸 '전체 설정을 따름', 목록은 `SFX_LIST` 그대로).
- `playSfx(power, z)`: 영역에 고른 효과음이 있으면 그것(전체 설정이 '끄기'면 다 끔). 부르는 곳 `physics.js impact`, `pointer.js` 놓을 때.
- 부위 칩이 채운다(C-4 표): 볼 피부 약하게 · 가슴·배 띠요옹 · 머리카락 옷 펄럭임 · 꼬리 뚀잉 · 귀 피부 문지름 · 옷자락 옷 펄럭임 · 기타 = 전체 설정.
- **터치 파일로 내보내기**: 전에는 효과음을 하나만 넣었다 → 전체 설정 + 영역마다 쓰인 효과음을 모두 넣는다(`touchSfxIds`, 받은 쪽은 `touchData.sfxs`). 예상 용량도 같은 목록으로 센다.

## F-2 폰 진동
- 터치 반응(톡 치기·빠른 튕김·끌다 놓기·길게 누르기)이 일어날 때 `navigator.vibrate`(세게 칠수록 조금 길게, 8~20ms).
- 소리 창 '칠 때 폰 진동'(기본 켬, 브라우저에 기억). 진동이 없는 기기(아이폰 등)는 스위치를 감추고 아무 일도 없다. 녹화 중·효과음 끔(플레이 화면 ❚❚)에는 진동하지 않는다.

## F-3 가끔 짓는 표정
- '3. 몸체 움직이기' 평소 표정 아래 `가끔 짓는 표정 [없음 / 표정]` + `얼마나 자주 [가끔·보통·자주]`(전체에 하나, `ambient.idleFace`·`idleEvery`, 저장·되돌리기에 들어감).
- 간격 12·7·4초(±30% 무작위)마다 0.4초에 올라와 1.2초 머물고 0.6초에 풀린다. 터치 반응 표정이 떠 있는 동안과 그 뒤 2초는 쉰다. 섞는 곳은 `faceActive()`의 'base' 쪽(새 길 없음).
- 연속 움직임 영상 녹화: 시작 때 간격 시계를 0으로, 끝 0.5초 안에는 새 표정을 시작하지 않는다.
- 검수 E10을 화면에 적음: '움직임 켜기'가 꺼지면 평소·가끔 표정 칸이 흐려지고 "움직임 켜기가 꺼져 있어 평소 표정·가끔 짓는 표정도 쉬고 있습니다."
