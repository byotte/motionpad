# G단계: 쓰다듬기 · 이음매 없는 반복(1단계 측정) (2026-11-17)

## G-1 쓰다듬기
- 판정(`pointer.js strokeCheck`): 한 영역 위에서 손가락을 떼지 않고 방향을 두 번 넘게 뒤집으며 0.6초 넘게 움직이고, 처음 누른 자리에서 영역 크기의 절반(반지름) 넘게 벗어나지 않으면 쓰다듬기.
- 판정 전 움직임은 평소 끌기 그대로, 판정된 순간부터 0.2초에 걸쳐 끌기 변위의 0.35배로 넘어간다(튀지 않게). 놓을 때 튕김·소리 없음(빠른 튕김과 겹치지 않게).
- 쓰다듬는 동안 효과음 '피부 문지름'(`skin-rub`)을 0.5초에 한 번 넘지 않게.
- 표정: 4-2 '표정 반응'에 `쓰다듬을 때 [없음 / 표정]`(영역 속성 `strokeFace`, 기본 ''). 0.5초에 걸쳐 올라와 머물고 손을 떼면 1.5초에 풀린다(`faceActive()`의 'touch' 쪽). 쓰다듬는 동안은 가끔 짓는 표정이 쉰다.
- '터치 종류별 배율'에 쓰다듬기 막대는 넣지 않았다(지시대로).
- 시험 `fix_check.js g`: 짧은 빠른 튕김은 쓰다듬기 아님 · 좌우 다섯 번 문지르면 판정 · 놓으면 풀림.
- 참고: F 커밋(`d4b36e7`)에서 머리카락·꼬리·옷자락 부위 칩의 효과음 세 줄이 이 커밋으로 넘어왔다(같은 줄에 '방향 긋기' 표시가 있어 나눌 때 섞였다). 이 커밋까지 오면 F 표대로다.
