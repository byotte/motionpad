# H단계: 편의 기능 (2026-11-17)

## H-1 움직임 설정 복사·붙여넣기
- 영역 메뉴(우클릭·길게 누르기)에 `움직임 복사`·`움직임 붙여넣기`. 복사하는 것 = 모양·위치·이름·몸체 여부·잠금·빈자리 채우기·축 위치(pivotX·Y·추가 축)·가이드 선·가지 선을 뺀 움직임 값 전부(부위 `preset`·`level`·효과음 포함).
- 프로젝트를 넘어 붙일 수 있게 브라우저에 둔다(`localStorage motionpad-motion-clip`). 붙여 넣을 것이 없으면 메뉴가 흐림. 붙여넣기는 되돌리기 지점 하나.

## H-2 숫자 직접 입력 · 기준값으로
- 조절 막대의 숫자를 누르면 그 자리에서 입력 칸(폰은 숫자 자판 `inputmode=decimal`). Enter·바깥 누르기 = 확정, Esc = 취소, 범위를 넘으면 끝 값으로.
- 숫자를 두 번 누르면(더블 클릭·더블 탭) 기준값으로(A-8 `valueBaseline` 그대로).
- 막대마다 따로 달지 않고 숫자 표시(`output`) 전체에 한 번에(zones.js 맨 아래). 값은 그 막대의 input 이벤트로 넣어 되돌리기·자동 저장이 따라온다.
- 화면에 보이는 단위로 받는다(바람 세기처럼 표시가 %로 바뀐 막대는 표시 함수로 배율을 재서 바꾼다).

## H-3 영역 숨기기 · 순서 바꾸기
- 숨기기: 영역 속성 `hidden`. 숨긴 영역은 움직이지 않고 터치에도 안 잡히고(물리·셰이더·CPU 그리기·빈자리 채우기·표정 반응에서 빠짐) 영상에도 반영된다. 목록에는 흐리게(줄 긋기) 남고, 목록의 점(●/◌)이나 영역 메뉴 `숨기기/보이기`로 켜고 끈다. 몸체는 숨기지 않는다.
- 순서: 영역 메뉴 `위로`·`아래로`(끌기는 하지 않음: 폰의 길게 누르기가 영역 메뉴라 겹친다). 뒤가 위. 몸체는 늘 맨 앞이라 못 옮긴다. 순서를 바꾸면 떠 있던 맞은 자리 자국을 지우고 마스크를 다시 만든다.

## H-4 그림 자르기 (범위: 자르기만, 크기 바꾸기는 다음 — 작업지시서 권고)
- 파일 메뉴 `그림 자르기…` → 그림 위에 틀(모서리 손잡이 넷, 안을 끌면 옮김, 바깥은 어둡게) + 아래 줄 `자유·원본·9:16·3:4·1:1`, 잘릴 크기(화소), `취소`·`자르기`(`crop.js`).
- 원본 파일(`imgBlob`)을 그 크기 그대로 잘라 새 원본을 만든다(JPEG·WebP는 같은 형식 95%, 그 밖은 PNG).
- 좌표 옮기기: 영역(타원·다각형은 모양 그대로 숫자만, 붓·래스터·기울인 타원은 384 격자로 다시 찍음), 축·추가 축·가이드 선·가지 선, 눈 깜빡임 점·앞머리 붓(굵기는 짧은 변 기준이라 비율을 맞춤), 얼굴 입·눈썹·귀. 틀 밖으로 완전히 나간 영역은 지운다.
- 되돌리기에 넣지 않는다: 자르기 전 확인창 "자르면 되돌릴 수 없습니다. 먼저 프로젝트를 저장해 두는 것을 권합니다."(지워질 영역이 있으면 이름도) → 자른 뒤 되돌리기 기록을 비운다.
- 시험 `fix_check.js h4`(2600×2600 네 색 그림을 (0.1,0.1)부터 0.6×0.6으로): 그림 1560×1560 · 왼쪽 위 영역 가운데 0.25,0.25 그대로 같은 빨강 화소 · 반지름 0.08/0.6 · 다각형·눈 점이 계산대로 · 기울인 타원은 격자로 다시 찍혀 가운데가 맞음 · 틀 밖 영역은 확인창에 이름이 나오고 지워짐.
