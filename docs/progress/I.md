# I단계: 얼굴 자동 초안 (시험판, 본판과 따로) — 2026-11-17

- 본판(`motionpad.html`)은 그대로. 시험판은 **`motionpad-face-draft.html`** 하나(https://byotte.github.io/motionpad/motionpad-face-draft.html). 폰에서 본판과 나란히 열어 비교한다.
- 소스는 따로 떨어진 가지 `face-draft`(로컬, 원격 가지에 올리는 것이 막히면 `backups/face-draft/face-draft.patch`에 같은 내용). 본판 가지에는 합치지 않았다.
- 들어간 것: 새 파일 `src/js/face-draft.js` 하나 + `index.html`·`app.html` 한 줄씩(+ CSS 두 줄). 빼려면 그것만 지우면 된다. 지금의 직접 찍기는 한 줄도 안 바꿨다. 초안은 지금과 같은 칸(눈 점·입·눈썹)에 값을 채울 뿐이라 저장 형식도 그대로.

## 쓰는 법
'2. 얼굴 · 눈 깜빡임'의 `자동 초안` → 두 눈의 양 끝을 차례로 4번 누름 → 눈꺼풀 위아래·눈썹·입 초안이 들어감(못 찾은 부위는 채우지 않고 "…은(는) 찾지 못했습니다. 직접 찍거나 그려 주세요.") → 찍힌 점·선의 점을 **끌어서 고친다** → `초안 완료`.

## 짐작하는 법(무거운 모델 없음)
- 눈꺼풀: 두 끝의 가운데에서 눈 선에 직각으로 훑어, 피부보다 어두운 가장 바깥(눈 윤곽선). 못 찾으면 눈 너비의 0.28배.
- 눈썹: 윗꺼풀 위로 눈 너비의 0.15~1.2배 띠에서, 열마다 눈에서 가장 가까운 어두운 점을 모아 이어진 가로 줄.
- 입: 두 눈 가운데에서 아래로 두 눈 사이 거리의 0.55~1.4배 띠, 폭 ±0.3배에서 같은 방식.

## 판정 (샘플 4장 5얼굴, `img/I-draft-samples.png`: 노랑 = 눈 점, 하늘 = 눈썹, 분홍 = 입)
| 그림 | 눈꺼풀 | 눈썹 | 입 |
|---|---|---|---|
| 기준 캐릭터(선 그림) | 조금 고치면 됨(눈동자 끝에 걸림) | **그대로 쓸 만함** | 틀림(턱 쪽 머리카락) |
| 001 실사풍 남자 | 조금 고치면 됨 | 틀림(머리카락) | 못 찾음(안 채움) |
| 002 왼쪽(모자) | 조금 고치면 됨 | 틀림(모자 그림자) | 틀림(턱선) |
| 002 오른쪽 | 조금 고치면 됨 | 틀림(앞머리) | 못 찾음(안 채움) |
| 003 치이카와풍 | 조금 고치면 됨 | 틀림(작은 기호) | 틀림(그릇 테두리) |

- 정리: 눈꺼풀은 대부분 조금만 끌어 고치면 된다. 눈썹은 선이 또렷한 그림체에서만 맞고, 실사풍은 머리카락·그림자를 잡는다. 입은 거의 틀린다. **사용자가 걱정한 대로 "고치는 것이 처음부터 찍는 것보다 번거로운" 경우가 많다.**
- 사용자가 주는 그림 5장 넘게로 더 해 봐야 판정이 완성된다(지금은 저장소 그림 4장). 해 보는 도구: `node tools/face-draft/try.js`(face-draft 가지).
- 권고(사용자가 정함): 짐작 전체를 채택하기보다, **'끌어 고치기'만 본판에 살리는 쪽**(지금 직접 찍기 뒤에 점을 끌어 고칠 수 있게). 채택하지 않으면 가지와 시험판 파일을 지우고 끝낸다.
