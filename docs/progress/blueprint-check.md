# 청사진 대조 점검표

`docs/BLUEPRINT.md`의 항목을 실제 프로그램(`src/`, `motionpad.html`)과 하나씩 맞춰 본 기록이다. 코드는 고치지 않았다.

- 상태 표기: **됨** / **부분** / **안 됨** / **확인 불가**(이 환경에서 볼 수 없는 것 — 실기기·취향 판단 등)
- 근거: 코드 위치(`파일:줄`) 또는 결과물 `motionpad.html`을 브라우저로 열어 실제로 눌러 본 결과(‘실행’으로 표시)
- 대상 커밋: 3-I 끝(`b7fcc46`)
