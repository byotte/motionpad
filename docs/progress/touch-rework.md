# 터치 재작업 · 갸웃/계속 돌기 · 편집 중 움직임 멈춤 · 빈자리 채우기 기본 켬 (2026-11-18, 사용자 요청)

시작 전 지점: 로컬 태그 `before-touch-rework`(= 커밋 `897ae83`).

## 1. 터치는 종류(방향)를 정하지 않는다
- '터치 움직임'의 `방향`(끄는 쪽으로 / 고정 위아래·좌우·대각선·확대축소) 칸을 없앴다. 옛 파일의 값은 읽어 두기만 하고 쓰지 않는다(그 값이 '고정'이던 옛 프로젝트는 이제 손가락을 따른다).
- 끌기: 늘 손가락 쪽으로.
- **톡 치기**: 누른 자리에서 영역 안쪽으로 밀린다 → 누른 쪽이 눌리고, 영역 전체가 살짝 밀려 반대쪽이 부푼다. 눌리면서 살짝 납작해진다. 누른 자리 둘레에 모이는 정도는 지금의 '잡아당김'. 놓으면 스프링으로 뾰잉 돌아온다(`physics.js impact`·`pressDirection`).
- **길게 누르기**: 0.4초부터 1.4초까지 누른 쪽이 점점 더 깊이 눌리고(전에는 영역 전체가 줄어들었다), **떼면 눌린 만큼 반대로 튀어 오르며** 돌아온다(뾰잉, 눌린 깊이만큼 소리도 조금 크게).
- 빠른 튕김(짧게 끌고 놓기)은 그대로 튕긴 쪽으로.

## 2. 새 영역은 '빈자리 채우기'를 켠 채로
- 새로 만드는 영역(타원·사각형·올가미·마술봉·붓)은 빈자리 채우기가 켜진 채로 만들어진다. 한 그림에 4개까지라 넘치면 끈 채로. 옛 프로젝트의 영역은 그대로.
- '계속 돌기'가 빈자리 채우기와 함께여야 자연스럽다는 것은 방향 칸의 설명(안내줄)과, 끈 영역에서 계속 돌기를 고를 때 안내줄에만 적었다(메뉴 이름에는 안 붙임).

## 3. 연속 움직임 방향에 '갸웃'·'계속 돌기'
- 갸웃: 한쪽으로 기울어 잠깐 머물고 반대쪽으로 기울어 머문다(사인을 잘라 양 끝에 머묾, 빠르기 1에서 한 번 왕복 약 5초). 각도는 세기에 따라 약 4.5°~18°.
- 계속 돌기: 한 방향으로 계속(빠르기 1에서 4초에 한 바퀴).
- 중심: 축을 찍었으면 그 점, 없으면 갸웃은 영역 아래쪽 가운데(목), 계속 돌기는 영역 가운데.
- 셰이더: 회전 각도는 `u_chainMid.w`(비어 있던 자리, 새 영역 배열 없음), 그림 가로세로 비 `u_aspect` 하나 추가. 회전은 크기 제한(.055·.08)과 그림 테두리 붙잡기 밖에서 통째로 더한다. 빈자리 채우기 영역은 떼어 낸 층이 통째로 돌고, 아닌 영역은 영역 안만 돈다(둘레 띠가 비틀림).

## 4. 영역을 그리거나 고치는 동안 저절로 움직임 멈춤
- 마술봉·올가미·도형·붓·지우개·이동, 축·가이드 선·입·눈썹·귀 찍기 도구를 쓰는 동안 연속 움직임(바람·호흡·물결·비틀림·흐름·갸웃·돌기·몸체 숨쉬기·흔들림)이 0.2초쯤에 걸쳐 잦아든다. '만져 보기'·플레이로 가면 다시 움직인다(`motionCalm`, controls.js). 터치 반응은 그대로.

## 같이 고친 버그
- 제목줄 오른쪽 켜기 스위치(얼굴·몸체·4-1)의 **동그란 스위치 자체를 누르면 안 켜지던 것**(A-7에서 생김. 글자 '켜기'를 누를 때만 됐다). 스위치를 누르면 브라우저가 그대로 켜고 끈다.
