# 화면 구조표 (상위 → 하위 분류, 2026-11-17)

레이아웃 분류 검수용. 같은 단계끼리는 같은 모양(글자 크기·굵기·상자)이어야 하고, 하위는 상위 안에 들어 있어야 한다.
디자인 규칙은 `docs/DESIGN-RULES.md`(글자 3단계: 큰 메뉴 / 항목 / 도움말, 묶음 상자 = 제목 없이 나누는 선 또는 제목 있는 접는 상자).

## 1단계: 화면 큰 구역
1. **상단바** — 로고·프로젝트 이름 / 메뉴 `파일` `소리` `설정` / 강조 버튼 `플레이`
2. **도구줄** — 도구 `붓 · 지우개 · 마술봉 · 올가미 · 도형 · 이동 · 화면 이동` | 영역 관리 `새 영역 · 복제 · 삭제`
3. **도구 옵션 줄** — 고른 도구의 옵션(붓 굵기, 선택 방식, 마술봉 범위, 올가미 옵션, 윤곽 보정 등)
4. **캔버스** — 그림 + 겹친 층(터치 표시, 갈라짐, 얼굴 이펙트, 편집 표시)
5. **안내줄** — 지금 할 일 한 줄
6. **아래 빠른 줄** — 되돌리기·다시 실행, 확대·축소, 돋보기, 손가락 보정(폰), 영역선, 터치 on/off
7. **옵션 패널**(PC 오른쪽, 폰 아래) — 아래 2단계
8. **감상(플레이) 화면** — 그림 + 구석 플레이어·녹화

## 2단계: 옵션 패널 섹션(번호 고정, 같은 단계)
- **1. 영역** — 영역 목록 / 이름·잠금 / 몸체 지정 / ▸경계(하위 상자) / ▸축과 가이드 선(하위 상자)
- **2. 얼굴 · 눈 깜빡임** [선택] [적용 체크] — 얼굴 목록(최대 3) / 눈 깜빡임·입·눈썹·귀 줄 / 표정 세부 설정(표정 5개 → 창)
- **3. 몸체 움직이기** — 대상(이미지 전체·몸체) / 호흡·흔들림 / 평소 표정(얼굴이 있을 때)
- **4. 부분 움직이기** — ▸움직임 프리셋 / ▸4-1 연속 움직임(▸기타 움직임 효과) / ▸4-2 터치 움직임
  - 4-2 안: 방향·세기·반발·잔진동·잡아당김·파동 → ▸터치 종류별 배율 → ▸표정 반응(얼굴이 있을 때) → ▸맞은 자리
- 패널 맨 아래: 선택 영역 색상·투명도

## 2단계: 대화창(창 제목 = 큰 메뉴 글자)
- 파일 메뉴: 새 그림 열기 / 프로젝트 열기·닫기·저장·이름 바꿔 저장 / 터치 파일로 내보내기 / 영상으로 내보내기 / 임시 보관된 프로젝트
- 소리 / 설정(색상 테마·화면 표시 품질) / 프로그램 정보(도움말 Tip·단축키)
- 확인창(askConfirm)·알림창(showNotice) / 영역 메뉴(우클릭·길게 누르기)
- **눈 깜빡임 창** — 도구줄(편집할 눈·초기화·앞머리 영역·되돌리기·확대) / 미리보기 / 설정
- **표정 세부 설정 창** — 도구줄(표정·프리셋 불러오기·원래 얼굴·되돌리기·확대·축소) / 왼쪽 미리보기(끌어 이동, 이펙트는 끌어 옮김) / 오른쪽 옵션:
  - 좌우 같이 조정
  - 상자 [눈썹·윗눈꺼풀·아랫눈꺼풀](소제목 셋, 상자 제목 없음) / 상자 [입] / 상자 [홍조: 면적·진하기·모양·귀까지]
  - 상자 [이펙트]: 탭(땀방울·눈물·반짝이·💢 화남·하트) → 모양(적용 안 함·디테일하게·캐주얼하게) → 그 이펙트 설정

## 검수 때 볼 점
- 같은 단계인데 모양이 다른 곳, 하위인데 상위처럼 보이는 곳(또는 반대), 다른 기능인데 한 묶음처럼 보이는 곳.
- 이름이 같은 것을 다른 뜻으로 쓰는 곳(예: '세기', '모양', '진하기').
- 얼굴이 없으면 표정 칸이 숨는지(초보자 화면은 단순해야 한다).
